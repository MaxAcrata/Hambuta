# Справочник команд Valheim Companion

Три группы: **консольные** (игровая консоль F5), **голосовые** (PTT) и **запуск микрофона**.

| Модуль | Версия | Где работает |
|---|---|---|
| ValheimCompanion (C#) | 0.5.2 | игра, консоль F5 |
| Voice (Python) | 0.5.0 | терминал / `mic` в консоли игры |

---

## 1. Консольные команды (`vc`)

Открыть консоль: Steam launch option **`-console`**, затем **F5**.
Команды `vc` доступны сразу после загрузки мода — **`devcommands` не нужен**.

| Команда | Действие | Пример |
|---|---|---|
| `vc spawn` | Заспавнить компаньона (primary `Skeleton_Friendly`) или перепривязаться | `vc spawn` |
| `vc spawn fallback` | Заспавнить запасного (`Skeleton`) | `vc spawn fallback` |
| `vc state` | Состояние компаньона (10 полей) | `vc state` |
| `vc status` | Статус move-job + bound + tagged NPC | `vc status` |
| `vc move here` | Отправить компаньона к игроку | `vc move here` |
| `vc move x y z` | Отправить к координатам | `vc move 100 40 -200` |
| `vc inspect` | Компоненты живого компаньона | `vc inspect` |
| `vc inspect ИмяПрефаба` | Компоненты префаба | `vc inspect Skeleton_Friendly` |
| `vc scan` | Все Characters + tamed/faction/tag/match | `vc scan` |
| `vc adopt` | Перепривязаться к ближайшему NPC | `vc adopt` |
| `vc cleanup` | Удалить всех companion-like NPC | `vc cleanup` |
| `vc cleanup keep` | Удалить всех, кроме текущего | `vc cleanup keep` |
| `vc xp` | Уровень и XP компаньона | `vc xp` |
| `vc xp add N` | Выдать N XP (отладка) | `vc xp add 100` |
| `vc despawn` | Удалить текущего компаньона | `vc despawn` |
| `vc help` | Справка | `vc help` |

**Чистый старт (0.5.1):** через ~5 с после загрузки мира плагин сам удаляет все companion-like NPC-остатки из сейва — при запуске **0 ботов**, компаньон появляется только после `vc spawn`. Если `vc spawn` успел выполниться раньше — зачистка пропускается.

**XP компаньона (0.5.2):** убийства компаньона дают XP (10–100, по здоровью жертвы), каждые **100 XP** — уровень: **+40 макс. здоровья** и полное лечение. Смотреть: `vc xp`, `vc state` (поля 11/12). XP сохраняются в мире.

### Семантика движения

| Параметр | Значение |
|---|---|
| Метод | только `MonsterAI.SetFollowTarget(marker)` |
| Успех | дистанция ≤ **3.5 m** 2 опроса подряд (0.5 s) |
| Таймаут | **30 s** + диагностика |
| Очистка | `StopMoving()`, `SetFollowTarget(null)`, ZDO `s_follow=""` |

## 2. Запуск голосового модуля (`mic`)

**Только из игровой консоли (F5).** После запуска окно Python можно свернуть — управление идёт через **CTRL** в игре.

| Команда | Действие |
|---|---|
| `mic` | Запустить голосовой модуль (PTT) |
| `mic stop` | Остановить |
| `mic status` | Состояние процесса |
| `mic help` | Справка |

### Порядок

1. Valheim → мир → консоль **F5** → `mic`
2. Вернуться в игру (окно Python свернуть, **не** закрывать)
3. **Зажать CTRL** → микрофон включается → сказать → **отпустить CTRL**
4. Команда выполняется
5. Стоп: `mic stop` в консоли или Ctrl+C в окне Python; при выходе из игры окно закрывается автоматически

```
mic
```

Диагностика без голоса (необязательно): `.venv\Scripts\python.exe run.py --text "стой"` из папки `voice`.

## 3. Голосовые команды (PTT)

**PTT:** зажать клавишу (по умолчанию **Left Ctrl**) → говорить → отпустить.
Микрофон включается **только на время удержания** клавиши.

| Сказать (по-русски) | Синонимы | IPC | Действие | Успех — это |
|---|---|---|---|---|
| **«Иди за мной»** | «следуй за мной», «за мной» | `FOLLOW_ME` | игрок — цель следования | `follow_target` ≠ пусто (не маркер) |
| **«Иди сюда»** | «подойди сюда», «подойди ко мне», «сюда», «иди ко мне» | `COME_HERE` | движение к позиции **игрока** (координаты считает игра) | move-job `succeeded` (≤ 3.5 m) |
| **«Стой»** | «остановись», «стой там», «прекрати» | `STOP` | очистить follow + `StopMoving()` | нет follow и нет move-job (2 опроса) |
| **«Статус»** | «как дела», «статус компаньона» | `STATUS` | печатает реальное состояние | блок состояния из игры |

Любая другая фраза → **«Повторите, пожалуйста»**, в игре **ничего**.

### Правила распознавания (без LLM)

1. Нормализация: регистр, `ё→е», пунктуация, пробелы.
2. Убрать заполнители: `пожалуйста`, `ну`, `э`, `а`, `командир`.
3. Точное совпадение с алиасами → выполнить.
4. Fuzzy (`difflib` ≥ 0.90) — только если кандидат один.
5. Два похожих → неоднозначно. Ни одного → неизвестно. Оба → «Повторите».

### Коды выхода `run.py --text "..."`

| Код | Значение |
|---|---|
| 0 | выполнено |
| 2 | пустая команда |
| 3 | неоднозначно |
| 4 | неизвестная команда |
| 5 | игра недоступна |
| 6 | игра отклонила |
| 7 | проверка результата не пройдена |

## 4. Настройки DSP и шума

### 4.1 В наушниках шум при включённом микрофоне (мониторинг Windows)

Это **не** DSP, а проигрывание микрофона в наушники.

1. ПКМ по звуку → **Звуки** → **Запись** → ваш микрофон → **Свойства** → **Прослушать**
2. Снять **«Воспроизводить с этого устройства»** → Применить

Windows 11: `Параметры → Система → Звук → Микрофон → Прослушивание` — **выкл**.

Также: Bluetooth **Hands-Free (HFP)** при включении микрофона даёт шум — используйте стерео/A2DP или провод/Realtek Mic. Sidetone в ПО гарнитуры — выключить.

### 4.2 DSP (голос vs шум)

| Ключ | По умолчанию | Что делает | Настройка |
|---|---|---|---|
| `highpass_hz` | `100.0` | режет гул/бас игры | `150–200` если бас мешает; выше — режет низ голоса |
| `trim_db` | `-50.0` | только тишину/SFX по краям | **не** выше `-40` — иначе обрезаются слова |
| `gate_db` | `-55.0` | мягкий гейт (речь не режется) | `-45`/`-40` если шипит после denoise |
| `denoise` | `true` | спектральное шумоподавление по профилю шума | `false`, если режет голос |

После каждой фразы в окне `mic`:
```
DSP: -18.3 dBFS -> -32.1 dBFS (hp=100Hz gate=-55dB denoise=True)
```
**Y заметно ниже X** = шум срезается.

Баланс по умолчанию: **речь важнее**. Если остался гул игры — `highpass_hz = 150`, затем `gate_db = -45`. `trim_db` вверх не поднимать.

Пример:
```toml
[audio.dsp]
highpass_hz = 250.0
trim_db = -30.0
gate_db = -40.0
denoise = true
```

Установка пакета denoise (если ещё нет):
```cmd
.venv\Scripts\python.exe -m pip install noisereduce
```

### Аппаратура и Windows (важнее DSP)

| Приём | Эффект |
|---|---|
| **Наушники**, а не колонки | нет обратной связи «игра → микрофон» |
| Микрофон гарнитуры | голос ближе, шумы дальше |
| Выключить «Воспроизводить с этого устройства» | Windows не пишет системный звук |
| Windows 11: «Фокусировка голоса» | системное шумоподавление |
| Приглушить музыку/эффекты в игре | меньше SFX в записи |
| NVIDIA Broadcast / RTX Voice | GPU-денойз до попадания в Python |

Подробнее: `voice/README_VOICE.md` §9.

### Прочие настройки голоса

| Ключ | По умолчанию | Назначение |
|---|---|---|
| `audio.mic_device` | `-1` | индекс микрофона (`mic` → `list_mics.py`) |
| `ptt.ptt_key` | `left ctrl` | клавиша PTT |
| `stt.model_path` | `models/vosk-model-small-ru-0.22` | модель Vosk |
| `ipc.base_url` | `http://127.0.0.1:8765` | мост в игру |
| `match.fuzzy_min_ratio` | `0.90` | порог fuzzy-совпадения |

В игре: `BepInEx\config\com.valheimcompanion.prototype.cfg` → `Voice.IpcEnabled`, `Voice.IpcPort`.

## 5. Шпаргалка

**Игровая консоль:**
```
mic
vc spawn          (если компаньона ещё нет)
vc status
mic stop
```

**Дальше только CTRL** (зажать → сказать → отпустить):
```
Иди за мной
Иди сюда
Стой
Статус
```

Голосом **только 4 команды**. Спавн, координаты, cleanup — консоль `vc`.
